# Homebrew Tap for Backtrack

Homebrew formulae for [Backtrack](https://github.com/backtrackstudio/backtrack) tools.

## Install

```bash
brew tap backtrackstudio/backtrack
brew install bt
```

## Update

```bash
brew update
brew upgrade bt
```

## Available Formulae

| Formula | Description |
|---------|-------------|
| `bt` | Track and restore project snapshots (macOS ARM64) |
